# 江东小乔使用说明

简单介绍一下辅助能干啥，配一个示例图做说明。

## 1. 辅助使用条件

* 辅助只能在windows上使用，不支持mac电脑和手机。
* 截止今日（填入发布时候的日期），辅助暂时只支持微信区，qq区将在后续版本中支持。
* 未来可能会支持手机，但并不确定多久后会支持。

**不懂解压的用户请看下面，懂的请跳过**

* 压缩的目的是为了传输文件更加方便，把一系列文件变成了一个文件包，同时降低需要传输的文件大小。
* 一般电脑上初始安装系统的时候，装电脑的人，都会贴心的安装一个压缩和解压工具。
* 如果电脑上确实没有解压工具，可以下载安装一个7zip。如果这一步不会，我建议找一个略懂电脑的朋友帮忙。
* 在压缩文件上点击鼠标右键，一般会出现类似于“解压文件...”，“解压到当前文件夹”，“解压到xiaoqiao”，不同的解压缩软件，出现的右键菜单文字可能会不同，但功能类似。
* “解压文件...”，相当于弹出一个框，来详细设置如何解压。“解压到当前文件夹”，是把压缩包中的文件全部解压出来放在当前文件夹。“解压到xiaoqiao”，相当于创建一个“xiaoqiao”（这个名字一般是压缩文件的名字）目录，并把所有的文件解压到这个新创建的目录下。
* 一般来说我们建议把辅助解压到新创建的那个目录下。
* 此外，由于辅助会经常被使用，我们建议把辅助放在一个自己经常能找到而且不会被误删的地方。

## 3. 游戏账号的侦测

### 3.1 在电脑上打开游戏

* 首先需要下载微信PC版本，注意：微信PC版2.9之后才支持打开微信小程序（小游戏属于小程序的一种）。
* 扫描登录微信PC版本。
* 在微信PC版本主界面上左下角找到小游戏按钮（左下侧边从下往上第3个按钮），点击启动胡莱三国。
* 如果一切顺利，那么会成功进入游戏。
* 注意事项
    * 目前测试发现，有部分win7用户，使用截止（此处为当前日期）的最新版本时，无法正常启动游戏，表现是加载一会儿后闪退。
    * 经过研究发现，是微信的兼容性问题，经过研究发现，有一个早期版本的微信（此处填入那个链接地址）能解决这个问题。
    * 如果有win7用户遇到这种问题，那么可以暂时使用我们提供的微信版本。期待微信早日解决这个问题。

### 3.2 完成游戏侦测

* 在解压后的文件目录下，双击“江东小乔.exe”（就是那个有美女图标的可执行文件）打开辅助。
* 游戏成功打开之后，在辅助上点击“游戏侦测”，如果有日志显示已经探测到用户，那么恭喜你侦测成功。
* 如果侦测不成功，那么请重新打开一下游戏，然后重新侦测。一般来说，肯定能成功。如果依旧有问题，请联系我们进行反馈。

## 4. 辅助功能说明

* 侦测到用户之后，就可以启动辅助了，如果侦测到多个用户，会弹出选项，让用户选择需要启动哪个用户。
* 用户点击开始之后，首先需要选择启动哪些功能。用户可以根据自己需要选择需要启动的功能。
* 有些功能，需要进一步进行配置。
* 大部分功能，用户都能一看就明白，但部分功能需要解释说明一下。下面是需要附加说明的内容：

### 4.1 挖矿功能附加说明

* 挖矿功能，分为两个部分，领取采矿奖励和挖矿功能。只有两项功能都勾选之后，才能执行自动挖矿。
* 矿产到时间之后，会自动触发采矿。
* 采矿后，会自动触发新一轮占矿。
* 如果被打劫，会自动触发一轮占矿。
* 找矿对象之属臣说明：
    * 选择在属臣中找矿的时候，将会自动在指定用户和他的属臣中找矿，如果属臣有属臣，也会继续找，一直到没有找到属臣为止。
    * 如果勾选了在属臣库中找矿，那么必须执行一次更新属臣库才能生效。
    * 更新属臣库的时候，将会递归查找指定类型（好友或排行榜）的用户的所有子属臣。
    * 更新属臣库的过程比较漫长，具体有多漫长，取决于这个属臣库的数量多少。
    * 更新属臣库的过程中如果因为某些原因（比如网络故障）导致更新中断，那么属臣库需要重建，否则一个用户都没有。目前辅助的设计是，只有属臣更新完成之后，才会保存属臣库。
    * 更新属臣库的时候，不会删除以前保存的属臣库，只会增加新的。当然，如果有重复的，会自动过滤。也就是说，你可以放心的多次更新属臣库，而不用担心让自己已经保存的属臣库变少，而只是更加丰富。
    * 保存的属臣库，是按照大区进行存储的。也就是说：同一个大区的游戏账号，属臣库是共享的。
    * 关于属臣的说明比较长，不过如果你真的看懂了上面所有内容，你找矿失败的概率将降低到1%以下，你的矿被打劫的概率会降低到2%以下。
* 占矿失败原因说明：
    * 体力不够会占矿失败。
    * 没有设置占矿阵容，会失败。辅助使用的占矿阵容是城门防守阵容，左中右分别对应大中小矿。
    * 如果当前设置的占矿阵容中，某个武将被其它矿使用了，会失败。例子：你设置的大矿占矿阵容中有徐晃，但中间你手动占矿一次，把徐晃用于占中矿了，那么辅助使用城门的大矿阵容占矿时，必定会失败。

### 4.2 剿匪功能附加说明

* 剿匪使用的战斗阵容，是最近一次的攻击阵容。
* 首次使用剿匪功能，除了勾选之外，还需要进行剿匪的详细参数设置。
* 超出当前设定部分的体力，会全部用于剿匪，因此注意留出部分体力用于占矿。
* 剿匪操作自从启动之后，每个小时会重复检查一次，如果有新的体力也会按设定自动用掉。

### 4.3 爬塔功能附加说明

* 爬塔使用的战斗阵容，是最近一次的攻击阵容。
* 爬塔属于一次性任务，也就是那种不会循环反复执行的任务。一旦停止，需要手动再次启动。
