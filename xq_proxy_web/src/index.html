江东小乔手机版使用说明

【前言】
本文将介绍如何用手机侦测胡莱三国的账号并上传到江东云。

江东小乔的安卓App已经发布，除证书外无需任何配置，不依赖网络环境，仅需安装一个不到2M的App：下载江东小乔安卓版

1. 新用户首次使用流程

  • 如果没有配置过环境，那么首先需要配置环境(点击查看详情)
  • 配置完成环境之后，如果没有云管理页面的地址，需要获取云地址(点击查看详情)。注意，安卓端使用江东小乔App侦测的用户，无需此操作。
  • 云地址获得之后请自行保存好，这个地址正常情况下不会变。

2. 老用户使用流程

注意，老用户是指已经配置好环境，且拥有云管理页面的地址的用户。并非是指用过江东小乔的用户，如果使用过江东小乔，但没有配置过手机端侦测环境，那么依旧需要先看一下上面的配置环境教程。

2.1 配置云端挂机参数

  • 在任意浏览器中打开云地址，可以看到各种设置项。
  • 点击下载，可以查看当前云端的设置。
  • 配置好各种设置后，点击上传即可，具体生效会在下一次云开始之后。

2.2 开始云端工作

  • 直接在云地址点击开始，即可开始云端工作。

2.3 账号侦测

  • 如果侦测环境没有发生变化，那么在你进入游戏的瞬间，账号侦测已经自动完成。
  • 如果侦测环境发生了变化，比如想换一个WiFi进行侦测，再次配置一下WiFi代理即可。
