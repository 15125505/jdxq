安卓设备配置说明

安卓设备直接下载江东小乔安卓版，安装后按照提示配置即可。

苹果设备配置说明

基本流程：配置证书→信任证书→配置WiFi代理→完成。

1.安装证书并信任

  • 首先，你需要保证本页面是在Safari浏览器中打开的。
  • 点击下载证书完成证书下载，浏览器会弹出一个窗口，点击“允许”。
  • 在系统的设置中进入通用，找到描述文件（iPad可以直接找到，但iPhone需要先进入VPN与设备管理），选择刚才下载的描述文件并进行安装。
  • 回到通用，找到关于本机，找到最下方的证书信任设置，启用对xiaoqiao的信任。

2.配置代理

  • 首先，你需要保证当前是使用WiFi上网，否则后续操作无法进行。
  • 在系统的设置中进入无线局域网，点击你连上的WiFi，展开其详情。
  • 在详情中找到最下方的配置代理，并选择自动。
  • 在下方的URL中，输入http://server-6.example.invalid/p.pac
  • 点击存储，配置大功告成。
  • 点击这个地址，如果正常访问，说明代理设置已经OK。如果页面无法打开，说明代理设置有问题。

3.苹果游戏侦测注意事项

  • 无论是QQ还是微信，进入游戏将会自动完成账号侦测。
