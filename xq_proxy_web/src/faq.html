江东小乔手机版疑难解答

【前言】
本文是一些常见问题的解答，遇到任何问题，别着急，从头到尾仔细看一下本文。如果发现新的问题，我会统一更新在这个文档中。

通用疑难解答

1. 是不是手机侦测只能给江东云用户使用，江东小乔以后抛弃免费用户了？

  • 手机侦测确实只能江东小乔的云用户使用，因为其侦测信息是给云端使用的。
  • 但PC端的用户，依旧可以使用免费的小乔PC版本。
  • 我不仅不会抛弃免费用户，反而会在把现有功能完善之后，借助手机端侦测的技术手段，对PC端的侦测进行大幅度优化。

iOS端疑难解答

1. 我怎么知道我有没有侦测成功？

  • 在你的云管理页面，能看到用户信息上传的时间——那就是你最近一次成功侦测的时间。看那个时间，你就知道你刚才是否侦测成功了。

2. 配置侦测环境是否需要安装第三方的app？

  • 苹果用户完全不需要。

3. 是否必须要有WiFi的情况才能侦测账号？

  • 是的，因为在苹果和安卓设备中，代理只能针对WiFi进行设置。
  • 但根据经验得知，一般来说，一天侦测一次，在大部分情况下都够用。所以，你一天之内只要有那么几分钟有WiFi都够了。
  • 你如果在海上或者沙漠这种死活没WiFi的地方，用另外一个手机开几分钟热点，也是可以的。

4. 配置代理之后，我的手机整个上不了网了，这是怎么回事？

  • 请检查代理配置是否出了问题。

5. 那个获取云地址流程每次都要进行吗？

  • 单独列出这个问题，是因为很多人问。
  • 答案是：不是的，云地址获取流程唯一的作用就是获取你这个账号的云链接。
  • 如果以前在PC版侦测过账号，在江东那儿获取的网页版，就是云地址。这个功能的目的是给那些从未获得过云地址的用户使用的。获得一次之后，保存下来就行。如果PC版侦测过，也可以直接在PC版江东小乔上获取到这个地址。

6. 代理配置之后，我的手机可以上网，但胡莱进不去，这是怎么回事？

  • 如果证书配置不正确，或者缺少了步骤（比如苹果手机没有进行信任设置），就会出现这种情况，你需要重新检查自己的证书配置。

安卓端疑难解答

1. 小乔App开启侦测后，游戏进不去是怎么回事？

  • 首先，游戏进不去，不一定影响你侦测。有时候游戏页面报错，但侦测已经成功了。你回到App上看一眼，是否已经侦测成功了。
  • 有些平台不支持直接侦测（需要额外配置），在下一条疑难解答中有对这种情况的解答。

2. 江东小乔的App支持哪些平台？

  • 首先说结论：目前已知所有平台都能成功侦测。
  • 微信和QQ这两个最大的平台，最简单的侦测方式：微信用户使用胡莱三国微信端App打开游戏，QQ用户可以通过QQ小程序登录进入游戏可以成功侦测。
  • 微信的胡莱App也是可以直接侦测的。当然，能够直接侦测的平台，并不仅限上面的两种。
  • 另外，上面列了一些能直接侦测的平台，还有一些平台安全性非常高，如果非要侦测它也是有办法的。
    • 首先，在手机上安装一个支持XPosed模块的App，比如“伏羲x”或类似软件。
    • 启用XPosed之后，再安装JustTrustMe模块，这样之后，在这种环境下运行的App，将不再检查数字证书。
    • 以上软件的安装和使用教程，此处不再详述（以后有空再加）。
    • 在“伏羲x”或者类似环境中启动需要侦测的软件，比如微信或抖音，正常打开游戏即可被小乔的App侦测到。注意：小乔的App无需运行在第三方框架中。
    • 目前测试通过这种方式能侦测的软件，有微信小程序、抖音小程序、腾讯动漫小程序等。理论上，所有平台都能通过这种方式支持。刚才的几个例子，都是正常情形下无法成功而通过上述手段可以成功的。
    • 但总而言之，目前需要这样做的平台非常小众（虽然微信端不能直接侦测，但微信端可以通过QQ浏览器侦测，而无需上述操作）。而且不到万不得已，不建议使用这种手段。

3. 我证书验证也通过了，但游戏始终进不去，也不报任何错误，这是怎么回事？

  • 之前遇到过这么一个案例，我也不知道他是怎么回事，但他重启手机之后就好了。

4. 配置证书之后，系统总是提示我“网络可能收到监控”，这个很危险吗？

  • 数字证书是互联网世界用来保护信息安全的，部署的那个证书，是江东小乔颁发的，系统认为它不安全很正常。
  • 但请不要害怕，如果证书是小乔颁发的，那么只有小乔有作恶的能力，我可以承诺绝不会获取侦测信息之外的任何信息。另外，侦测时才开启小乔，侦测后就关掉小乔，这样也能更加安心。
  • 我只能承诺小乔的证书无威胁，普通用户仍旧不要轻易安装未知来源的数字证书。
