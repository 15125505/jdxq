# 简介

> **作者寄语**：江东小乔的公众号消失之后，一直没有系统性地介绍江东小乔使用方法的地方。我一直希望能有个地方可以快速的教大家上手，但由于我工作过于繁忙，一直也没能顾得上这个事情。这个周末，我痛定思痛，觉得整理一份文档出来，希望能对大家有所帮助。

## 江东小乔是什么

曾经，有一个胡莱三国的玩家，入坑之后备受挖矿的煎熬。而那时正好因为新冠导致被隔离了2个月，于是他决定开发一个自动挖矿的工具，于是江东小乔诞生了。

## 江东小乔的工作原理

江东小乔的工作原理其实很简单，首先是抓取和游戏服务器通信所需要的凭证（在江东小乔中我称之为**侦测**）。然后模拟玩家的操作和游戏服务器进行通讯。

但是凭证的抓取是一个比较复杂的过程，在Windows上和iOS以及安卓上，江东小乔分别使用了不同的手段来获取这个凭证。这儿我就不详细展开了，以后我有空的时候，我会详细进行介绍。

## 江东云是什么

在开发完江东小乔之后，我发现电脑如果24小时开机，不仅很吵，而且很费电。因此我额外开发了一套江东云，可以让挂机行为在云端进行。

## 江东小乔收费吗

江东小乔是完全免费的，你可以完全免费地使用江东小乔来帮你挖矿和进行一系列繁琐的操作。如果你有一台电脑，那么你可以在电脑上完全免费地使用江东小乔的全部功能。

但是，**江东云**并不是免费的。因为江东云的服务器是需要额外的成本的。江东云的好处是你即便没有电脑，依旧可以使用江东小乔，或者说你有电脑，但不想电脑24小时开机却又希望24小时挂机。

## 江东小乔的宗旨

我希望江东小乔能够帮助玩家解决一些繁琐而重复性地工作，让玩家能够更好地享受游戏，而不是被游戏所束缚。

但是，江东小乔不希望对游戏平衡造成影响，也不希望影响玩家的游戏体验。江东小乔绝对不会去寻找游戏的漏洞，也不会去破坏游戏的平衡。

江东小乔会帮你做一些事情，但不会帮你全部的事情。

我希望大家能快乐游戏、享受游戏。我希望有一天，我能做一个游戏，让大家都能快乐地玩。
