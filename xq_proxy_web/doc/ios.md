# 江东小乔ios端使用说明

> 对于普通的用户而言，安装iOS应用只能从应用商店中进行。但开发一个应用并上传到应用商店是比较费劲的，尤其是对于江东小乔这样的软件。因此，我就不额外提供iOS应用来辅助进行江东小乔的侦测了。
> 但幸运的是，iOS的封闭性导致它在某些系统功能上不像安卓那么五花八门需要适配。所以，我们可以通过一些其它的手段来进行侦测。

## 1. 侦测环境配置

> 侦测环境配置，只需要进行一次，以后就可以一直使用了。

### 1.1 安装证书并信任
* 首先，你需要保证本页面是在`Safari浏览器`（在微信中打开是不行的）中打开的。
* 点击[下载证书](http://server-6.example.invalid/xiaoqiao.cer)完成证书下载，浏览器会弹出一个窗口，点击“允许”。
* 在系统的`设置`中进入`通用`，找到`描述文件`（iPad可以直接找到，但iPhone需要先进入`VPN与设备管理`），选择刚才下载的描述文件并进行安装。
* 回到`通用`，找到`关于本机`，找到最下方的`证书信任设置`，启用对`xiaoqiao`的信任。

### 1.2 配置网络代理

* 首先，你需要保证当前是使用WiFi上网，否则后续操作无法进行。
* 在系统的`设置`中进入`无线局域网`，点击你连上的WiFi，展开其详情。
* 在详情中找到最下方的`配置代理`，并选择`自动`。
* 在下方的URL中，输入`http://server-6.example.invalid/p.pac`。
``` html
http://server-6.example.invalid/p.pac
```
* 点击`存储`，配置大功告成。
* 点击<a href="http://server-21.example.invalid/" target="_blank">这个地址</a>，如果正常访问，说明代理设置已经OK。如果页面无法打开，说明代理设置有问题

## 2. 使用方法

### 2.1 获取云地址

> 配置完成环境之后，如果没有云管理页面的地址，需要<a href="http://server-6.example.invalid/newUser.html" target="_blank">获取云地址(点击查看详情)</a>。
> 
> 云地址获得之后请自行保存好，这个地址正常情况下不会变。

### 2.2 侦测账号

> 无论是QQ还是微信，进入游戏将会自动完成账号侦测。

### 2.3 配置云端挂机参数

* 在任意浏览器中打开云地址，可以看到各种设置项。
* 点击下载，可以查看当前云端的设置。
* 配置好各种设置后，点击上传即可，具体生效会在下一次云开始之后。
* 注意：如果云端配置不需要更新的话，那么配置一次就可以了，以后就不需要再配置了。

### 2.4 开始云端挂机

> 直接在云地址点击开始，即可开始云端工作。


## 常见问题

* 我怎么知道我有没有侦测成功？
   * 在你的云管理页面，能看到用户信息上传的时间——那就是你最近一次成功侦测的时间。看那个时间，你就知道你刚才是否侦测成功了。
* 配置侦测环境是否需要安装第三方的app？ 
   * 苹果用户完全不需要。
* 是否必须要有WiFi的情况才能侦测账号？ 
   * 是的，因为在苹果和安卓设备中，代理只能针对WiFi进行设置。
   * 但根据经验得知，一般来说，一天侦测一次，在大部分情况下都够用。所以，你一天之内只要有那么几分钟有WiFi都够了。
   * 你如果在海上或者沙漠这种死活没WiFi的地方，用另外一个手机开几分钟热点，也是可以的。
* 配置代理之后，我的手机整个上不了网了，这是怎么回事？
   * 请检查代理配置是否出了问题。
* 那个获取云地址流程每次都要进行吗？
   * 单独列出这个问题，是因为很多人问。
   * 答案是：不是的，云地址获取流程唯一的作用就是获取你这个账号的云链接。
   * 如果以前在PC版侦测过账号，在江东那儿获取的网页版，就是云地址。这个功能的目的是给那些从未获得过云地址的用户使用的。获得一次之后，保存下来就行。如果PC版侦测过，也可以直接在PC版江东小乔上获取到这个地址。
* 代理配置之后，我的手机可以上网，但胡莱进不去，这是怎么回事？
   * 如果证书配置不正确，或者缺少了步骤（比如苹果手机没有进行信任设置），就会出现这种情况，你需要重新检查自己的证书配置。
